# المكتبة — نظام الطلبيات (نسخة محدّثة)

موقع ثابت (بدون سيرفر أو قاعدة بيانات) لعرض المنتجات وإرسال الطلبية عبر واتساب، مع صفحة تدريبات مجانية.

## الجديد في هذه النسخة

1. **تثبيت التطبيق على أندرويد (PWA)**
   - `manifest.json` + `sw.js` + أيقونات `icons/` → المتصفح يعرض «تثبيت التطبيق».
   - زر «📲 تثبيت الآن» يظهر تلقائيًا عند دعم المتصفح (Chrome/Edge على أندرويد).
   - لو المتصفح يدعم التثبيت بضغطة زر: الضغط على «تثبيت التطبيق» يفتح نافذة التثبيت الأصلية مباشرة بدون خطوات.
   - الخطوات اليدوية تظهر فقط لو المتصفح مش بيسمح بالتثبيت المباشر (مثل سفاري على iPhone).
   - خطوات يدوية لأصحاب iPhone (سفاري → مشاركة → إضافة إلى الشاشة الرئيسية).
   - مكان التثبيت: قائمة المساعدة ❓ → «تثبيت التطبيق»، وخطوة رابعة في الجولة التعريفية.
2. **المظهر الفاتح والغامق**
   - زر 🌙/☀️ في الشريط العلوي (وفي صفحة التدريبات).
   - الاختيار الافتراضي «حسب النظام»، ويُحفظ في `localStorage` تحت المفتاح `theme`.
   - يُطبّق قبل الرسم لمنع وميض الشاشة البيضاء.
3. **صفحة التدريبات المجانية** (`exercises.html`)
   - 8 تدريبات / 40 سؤالًا في مواد مختلفة (رياضيات، علوم، عربي، إنجليزي، دين، حاسب).
   - فلترة حسب الصف، تصحيح فوري مع شرح بعد كل سؤال، صفحة نتيجة + مراجعة الأخطاء.
   - أفضل نتيجة تُحفظ في `localStorage` تحت المفتاح `quizBest`.

## الملفات

| الملف | الوظيفة |
|---|---|
| `index.html` | واجهة المتجر + نوافذ التثبيت/الجولة التعريفية |
| `style.css` | التنسيق + متغيّرات المظهرين |
| `app.js` | منطق المتجر والسلة والطلبيات والمظهر والتثبيت |
| `exercises.html` / `exercises.css` / `exercises.js` | صفحة التدريبات المجانية |
| `manifest.json` | بيانات تطبيق الويب (PWA) |
| `sw.js` | عامل الخدمة (العمل بدون إنترنت + التثبيت) |
| `icons/` | أيقونات التطبيق 192 و512 |
| `products_v20260511234705.js` | بيانات المنتجات (كما هي بدون تغيير) |

## التشغيل محليًا

لا بد من سيرفر محلي (فتح `index.html` مباشرة يمنع عمل عامل الخدمة):

```powershell
py -m http.server 8000
# ثم افتح http://localhost:8000
```

## النشر

- ارفع محتويات المجلد كما هي إلى GitHub Pages أو أي استضافة ثابتة.
- كل المسارات نسبية، لذلك يعمل الموقع داخل مجلد فرعي أيضًا.
- عامل الخدمة يحتاج HTTPS (أو localhost) — GitHub Pages يوفّره تلقائيًا.

## عند تحديث الملفات لاحقًا

غيّر رقم الكاش في أول `sw.js`:

```js
const CACHE = 'almaktaba-v3';
```

ثم افتح الموقع مرتين متتاليتين حتى يُفعّل الإصدار الجديد.
